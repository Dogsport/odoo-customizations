October 2026 invoice PDFs

03.11.2026 · Odoo 19 production · Hamza Mohsin · request: Patricia · Status: DONE

Problem

  • The tax office package for October goes out on 04.11. Posted invoices and credit notes need a stored invoice PDF.
  • Print → Invoice PDF only downloads the file. It does not store it on the invoice.
  • Send in bulk has no e-mail checkbox ("79 invoice(s) by Email"), so it can't be used without e-mailing customers.

Solution

Single invoice in the UI: Send → untick "by Email" → Generate. This stores the PDF and sends no e-mail.

For the rest, the same wizard was run in the Odoo.sh shell (odoo-bin shell), one document at a time:

wiz = env['account.move.send.wizard'].with_context(active_model='account.move', active_ids=m.ids).create({'move_id': m.id})
wiz.sending_methods = False   # default ['email'] must be cleared
wiz.action_send_and_print()
env.cr.commit()

Scripts: 1_count_missing.py · 2_generate_pdfs.py · 3_verify.py

Side effects

  • Generated documents are marked "Sent" (is_move_sent). No e-mail is sent.
  • The shell runs as superuser (OdooBot).

Learnings

  • invoice_pdf_report_id is not stored, so it can't be used in a domain or UI filter ("Domain invalid"). Filter in Python instead.
  • An attachment search alone isn't reliable. E-mailed PDFs count as attachments, and "Generate" stores the PDF in a field the search doesn't see. Use both checks.
  • Print batches of 200 fail with wkhtmltopdf error -9. Use 100 or fewer.
  • Always test on staging first, then 1 record on production, then the rest.
