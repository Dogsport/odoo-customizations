2. How the carrier is decided now

Shopify checkout: customer picks a rate (e.g. "DHL Paket", "GLS EU")
  → Emipro creates the order, then writes the matching PRICE carrier (sale_order.py line 458)
  → rule "Shipping add" / "Shipping add – International (GLS)" fires on that edit
  → Germany: price carrier → DHL Parcel DE (25)   ·   other countries: → GLS Germany (2)
  → order confirmed → delivery takes the carrier over (Propagation of carrier)
  → GLS incoterm rules (EFTA 20 / Outside EU 40) add the incoterm on the delivery

5. Returns (DHL)

  • Rule "DHL – Automatic Return Receiver" (Production, since 20.10; Staging ID 41) fills deu on German DHL returns when the receiver is empty. Tested 27.10 on a manual return: Carrier → DHL Parcel DE → Save → deu filled, button changed from Get Receivers to Change Receiver.
  • Print Return Label only appears on real returns created with the Return button of the original delivery (standard Odoo: the return lines must be linked to the original moves). A return created via Returns → New never shows it.
  • Team rule: open the original delivery (or sales order → delivery) → Return → Print Return Label. No original delivery in Odoo → create the label in the DHL Geschäftskundenportal (Retoure, receiver deu) and book the return in Odoo without label.
  • "Change/Get Receivers" gives 401 … no apiproduct match found: the DHL developer app behind the API key lacks the API product the receiver lookup uses. Not needed for German returns.
  • Only receivers on the live DHL account: deu (Retoure Online, billed to IQ Dogsport) and deu_SZ (Selbstzahler). No international receivers.
  • Never click Print Return Label in Production for a test – it creates a real DHL return shipment. Test returns WH1/RET/00523 and 00524 to be cancelled.

9. Read-only checks (Odoo.sh → Production → SHELL)

9.1 Newest Shopify orders: order and delivery carrier

PGOPTIONS='-c default_transaction_read_only=on' psql -P pager=off -c "SELECT so.name, so.state, so.carrier_id AS order_carrier, c.code AS country, string_agg(DISTINCT sp.carrier_id::text, ',') AS delivery_carrier, so.create_date FROM sale_order so LEFT JOIN res_partner p ON p.id = so.partner_shipping_id LEFT JOIN res_country c ON c.id = p.country_id LEFT JOIN stock_picking sp ON sp.sale_id = so.id WHERE so.name LIKE '#IQD-%' GROUP BY so.id, so.name, so.state, so.carrier_id, c.code, so.create_date ORDER BY so.id DESC LIMIT 15;"

9.2 All carriers with type and Shopify code (after any Shopify rate change)

PGOPTIONS='-c default_transaction_read_only=on' psql -P pager=off -c "SELECT id, to_jsonb(c)->'name'->>'en_US' AS name, c.delivery_type, c.shopify_code, c.shopify_source, c.create_date FROM delivery_carrier c WHERE c.active ORDER BY id;"

9.3 Open deliveries still on a price carrier

PGOPTIONS='-c default_transaction_read_only=on' psql -P pager=off -c "SELECT so.name, sp.name AS delivery, sp.state, sp.carrier_id FROM stock_picking sp JOIN stock_picking_type spt ON spt.id = sp.picking_type_id LEFT JOIN sale_order so ON so.id = sp.sale_id LEFT JOIN delivery_carrier dc ON dc.id = sp.carrier_id WHERE spt.code = 'outgoing' AND sp.state NOT IN ('done','cancel') AND (sp.carrier_id IS NULL OR dc.delivery_type = 'fixed') ORDER BY sp.id DESC;"

9.4 Saved rule domains and triggers

PGOPTIONS='-c default_transaction_read_only=on' psql -P pager=off -c "SELECT a.id, to_jsonb(a)->>'name' AS name, a.active, to_jsonb(a)->>'filter_domain' AS apply_on, (SELECT string_agg(f.name, ',') FROM base_automation_ir_model_fields_rel r JOIN ir_model_fields f ON f.id = r.ir_model_fields_id WHERE r.base_automation_id = a.id) AS when_updating FROM base_automation a WHERE a.id IN (5, 6, 7, 8, 45);"

9.5 What each rule action writes

PGOPTIONS='-c default_transaction_read_only=on' psql -P pager=off -c "SELECT s.base_automation_id AS rule, to_jsonb(a)->>'name' AS rule_name, a.active, f.model, f.name AS field, s.value FROM ir_act_server s JOIN base_automation a ON a.id = s.base_automation_id LEFT JOIN ir_model_fields f ON f.id = (to_jsonb(s)->>'update_field_id')::int WHERE s.state = 'object_write' ORDER BY 1;"

9.6 DHL deliveries without tracking number (label missing)

PGOPTIONS='-c default_transaction_read_only=on' psql -P pager=off -c "SELECT sp.name, sp.origin, sp.state, sp.date_done FROM stock_picking sp JOIN delivery_carrier dc ON dc.id = sp.carrier_id WHERE dc.delivery_type = 'dhl_parcel_de' AND sp.state = 'done' AND sp.carrier_tracking_ref IS NULL ORDER BY sp.id DESC LIMIT 20;"
