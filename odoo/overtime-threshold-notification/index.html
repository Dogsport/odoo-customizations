Overtime threshold notification: weekly check + month-end summary

Live — weekly check Open — month-end summary first real run 31.10.2026
22.10.2026 · Production (iq-dogsport.odoo.com) · hr.employee · Scheduled Action
Prepared for: Dr. Florian Knabl

What was achieved

  • Replaced the existing "Daily Overtime Threshold Check" cron's logic: it used to compare each employee's lifetime overtime balance (total_overtime) to a threshold, which never resets — once crossed, an employee stayed flagged indefinitely even after the underlying overtime week was long over.
  • New logic sums each employee's actual clocked overtime (already net of the ArbZG break deduction) over a rolling 7-day window, and compares that to a threshold scaled to that employee's own weekly contracted hours (10% currently, configurable in Settings → Attendances → Extra Hours — no code change needed to adjust the percentage).
  • Notification goes to the employee's manager plus all Administrators (currently Florian or the relevant manager, Hamza, Patricia) as a to-do activity, with the exact numbers written into the note. Duplicate to-dos are prevented while one is still open.
  • Added a second, independent block to the same cron: on the last calendar day of each month, it totals each employee's full month-to-date overtime and posts a separate "Monthly overtime summary" to-do to the same recipients — satisfies the follow-up ask for monthly visibility, not just weekly threshold breaches.
  • Cleaned up 15 stale "Overtime threshold exceeded" to-dos that the old (incorrect) lifetime-balance logic had created for 6 employees.
  • Live-tested the weekly check after the rewrite: correctly flagged only the one employee genuinely over their weekly threshold, and correctly cleared employees who still carry a high lifetime balance but had a normal recent week.
  • No new fields, views, or groups — this was a code-only change inside an automation that already existed.

What is left

  • Monthly summary block is unverified in production. It has only ever run against a date that isn't month-end, so the branch that actually posts the summary has never executed for real. First real run is 31.10.2026 — needs a manual check afterwards that it created the expected to-dos with correct hours per employee.
  • Threshold percentage is still a single company-wide setting (10%) — no per-employee override exists yet if that's ever needed.
  • No email/digest option — notifications are Odoo activity to-dos only, not emails, by design so far.
  • Florian has not yet confirmed the recipient list (manager + both Administrators) is the right long-term group, or whether it should narrow over time.

Automation rule

SettingValue
TypeScheduled Action (ir.cron)
NameDaily Overtime Threshold Check
ModelEmployee (hr.employee)
RunsEvery 1 day, 9:59 AM
RecipientsEmployee's manager (parent_id.user_id) + Administrators (base.group_system)
DedupSkips creating a new to-do if one of the same summary is already open for that employee/user pair
company = env.company
today = datetime.date.today()

# --- Weekly overtime threshold check (last 7 days) ---
threshold_percent = company.x_overtime_threshold_percent or 0.0
if threshold_percent > 0:
    Employee = env['hr.employee'].sudo()
    Attendance = env['hr.attendance'].sudo()
    Activity = env['mail.activity'].sudo()
    activity_type = env.ref('mail.mail_activity_data_todo')
    hr_model_id = env['ir.model']._get_id('hr.employee')
    admin_users = env.ref('base.group_system').sudo().user_ids
    window_start = today - datetime.timedelta(days=6)
    window_start_dt = datetime.datetime.combine(window_start, datetime.time.min)
    window_end_dt = datetime.datetime.combine(today, datetime.time.max)
    employees = Employee.search([('company_id', '=', company.id)])
    for emp in employees:
        calendar = emp.resource_calendar_id
        if not calendar or not calendar.hours_per_week:
            continue
        threshold_hours = calendar.hours_per_week * (threshold_percent / 100.0)
        attendances = Attendance.search([
            ('employee_id', '=', emp.id),
            ('check_in', '>=', window_start_dt),
            ('check_in', '<=', window_end_dt),
        ])
        week_overtime = sum(attendances.mapped('validated_overtime_hours'))
        if week_overtime <= threshold_hours:
            continue
        recipients = env['res.users']
        if emp.parent_id and emp.parent_id.user_id:
            recipients |= emp.parent_id.user_id
        recipients |= admin_users
        note = (
            "<p><strong>%s</strong> worked %.2f overtime hours in the last 7 days "
            "(%s to %s), above the %.0f%% threshold of their %.1fh/week contract "
            "(threshold: %.2f hours).</p>"
            % (emp.name, week_overtime, window_start, today, threshold_percent,
               calendar.hours_per_week, threshold_hours)
        )
        for user in recipients:
            existing = Activity.search([
                ('res_model', '=', 'hr.employee'),
                ('res_id', '=', emp.id),
                ('activity_type_id', '=', activity_type.id),
                ('user_id', '=', user.id),
                ('summary', '=', 'Overtime threshold exceeded'),
            ], limit=1)
            if existing:
                continue
            Activity.create({
                'res_model': 'hr.employee',
                'res_model_id': hr_model_id,
                'res_id': emp.id,
                'activity_type_id': activity_type.id,
                'user_id': user.id,
                'summary': 'Overtime threshold exceeded',
                'note': note,
                'date_deadline': today,
            })

# --- Monthly overtime summary (fires only on the last calendar day of the month) ---
if today.month == 12:
    next_month_start = today.replace(year=today.year + 1, month=1, day=1)
else:
    next_month_start = today.replace(month=today.month + 1, day=1)
last_day_of_month = next_month_start - datetime.timedelta(days=1)
if today == last_day_of_month:
    Employee = env['hr.employee'].sudo()
    Attendance = env['hr.attendance'].sudo()
    Activity = env['mail.activity'].sudo()
    activity_type = env.ref('mail.mail_activity_data_todo')
    hr_model_id = env['ir.model']._get_id('hr.employee')
    admin_users = env.ref('base.group_system').sudo().user_ids
    month_start = today.replace(day=1)
    month_start_dt = datetime.datetime.combine(month_start, datetime.time.min)
    month_end_dt = datetime.datetime.combine(today, datetime.time.max)
    employees = Employee.search([('company_id', '=', company.id)])
    for emp in employees:
        calendar = emp.resource_calendar_id
        if not calendar or not calendar.hours_per_week:
            continue
        attendances = Attendance.search([
            ('employee_id', '=', emp.id),
            ('check_in', '>=', month_start_dt),
            ('check_in', '<=', month_end_dt),
        ])
        month_overtime = sum(attendances.mapped('validated_overtime_hours'))
        if month_overtime <= 0:
            continue
        recipients = env['res.users']
        if emp.parent_id and emp.parent_id.user_id:
            recipients |= emp.parent_id.user_id
        recipients |= admin_users
        note = (
            "<p><strong>%s</strong> worked %.2f extra hours in total during %s "
            "(%s to %s).</p>"
            % (emp.name, month_overtime, today.strftime('%B %Y'), month_start, today)
        )
        for user in recipients:
            existing = Activity.search([
                ('res_model', '=', 'hr.employee'),
                ('res_id', '=', emp.id),
                ('activity_type_id', '=', activity_type.id),
                ('user_id', '=', user.id),
                ('summary', '=', 'Monthly overtime summary'),
                ('date_deadline', '=', today),
            ], limit=1)
            if existing:
                continue
            Activity.create({
                'res_model': 'hr.employee',
                'res_model_id': hr_model_id,
                'res_id': emp.id,
                'activity_type_id': activity_type.id,
                'user_id': user.id,
                'summary': 'Monthly overtime summary',
                'note': note,
                'date_deadline': today,
            })
