Product data queues stuck – duplicate Shopify template links (27.10.2026)

PDF version

Status 27.10.2026: cause proven and fixed for 4 of 6 products. Follow-up of Shopify duplicate mappings (26.10.2026) – this time on the product (template) level.

Odoo 19 Production · Emipro Shopify connector. All checks read-only; changes = archiving wrong link records one at a time with before/after checks.

1. Symptom

Product Data Queues stuck in Draft / Partially Completed since 23.10.2026 19:10 (PDQ006640 … PDQ006762), 27 draft lines. Server log:

product_data_queue_line.py, line 118, in process_product_queue_line_data
ValueError: Expected singleton: product.template(89, 178)

2. Cause

  • One Shopify product linked to two or three Odoo templates in shopify.product.template.ept. The connector crashes and the whole queue run stops – products behind the broken line stay Draft too.
  • All 17 duplicate links (and 178 template + 601 variant links in total) have write_date 23.10.2026 13:29:21 UTC – the instance reactivation switched the intentionally archived old links back on (written by the user who reactivated).
  • Proof: the same products processed fine until 22.10 (Wurfversteck 15× done, PSD 21×, Top-Matic 13×) and only drafts since 23.10.
  • Not caused by archiving mappings 749/1169 on 26.10 (that was the variant table).

4. Procedure (one link at a time)

  1. Before check: variant links under the wrong and the correct template link (query 6.2). Stop if anything under the wrong link points to an active product that has no twin under the correct link.
  2. Open /odoo/shopify.product.template.ept/<ID> → check Shopify Template Id and Product Template → ⚙ → Archive. Never Delete, never Publish/Unpublish (those talk to Shopify), never Export.
  3. After check (query 6.3) → wrong f, correct t.
  4. Process the affected queue manually; never "Set To Completed" (skips the import).

Archiving a link sends nothing to Shopify and changes no product, stock or order. Undo: filter Archived → Unarchive.

6. Read-only checks

6.1 Shopify products with more than one active template link

PGOPTIONS='-c default_transaction_read_only=on' psql -P pager=off -c "SELECT to_jsonb(t)->>'shopify_tmpl_id' AS shopify_product, count(*) AS active_layers, string_agg(t.id::text || '->' || t.product_tmpl_id::text, ', ') AS layer_to_odoo_template FROM shopify_product_template_ept t WHERE t.active AND t.shopify_instance_id = 1 GROUP BY 1 HAVING count(*) > 1 ORDER BY 1;"

6.2 Variant links under two template links (replace 316, 324)

PGOPTIONS='-c default_transaction_read_only=on' psql -P pager=off -c "SELECT v.id, to_jsonb(v)->>'variant_id' AS shopify_variant, (to_jsonb(v)->>'shopify_template_id') AS tmpl_layer, v.product_id, pp.default_code, pp.active AS product_active, v.active AS link_active FROM shopify_product_product_ept v JOIN product_product pp ON pp.id = v.product_id WHERE (to_jsonb(v)->>'shopify_template_id')::int IN (316, 324) ORDER BY 2, 3, 1;"

6.3 After check (replace IDs)

PGOPTIONS='-c default_transaction_read_only=on' psql -P pager=off -c "SELECT 'tmpl' AS t, id, product_tmpl_id, active FROM shopify_product_template_ept WHERE id IN (316, 324) UNION ALL SELECT 'var', id, product_id, active FROM shopify_product_product_ept WHERE id IN (1169,1170,1171,1172,1173,1195,1196,1197,1198,1199,1280) ORDER BY 1, 2;"

6.4 Stuck queue lines with status

PGOPTIONS='-c default_transaction_read_only=on' psql -P pager=off -c "SELECT qd.name AS queue, q.id AS line, left(to_jsonb(q)->>'name', 40) AS product, q.state FROM shopify_product_data_queue_line_ept q JOIN shopify_product_data_queue_ept qd ON qd.id = (to_jsonb(q)->>'product_data_queue_id')::int WHERE q.state IN ('draft','failed') ORDER BY 1, 2;"

6.5 Health check per Shopify product (every variant exactly one active link to an active product)

PGOPTIONS='-c default_transaction_read_only=on' psql -P pager=off -c "WITH v AS (SELECT to_jsonb(t)->>'shopify_tmpl_id' AS sp, to_jsonb(v)->>'variant_id' AS sv, v.active AS la, pp.active AS pa, pp.default_code AS sku FROM shopify_product_product_ept v JOIN shopify_product_template_ept t ON t.id = (to_jsonb(v)->>'shopify_template_id')::int JOIN product_product pp ON pp.id = v.product_id WHERE to_jsonb(t)->>'shopify_tmpl_id' IN ('12109893730568','10709825028360')), per AS (SELECT sp, sv, count(*) FILTER (WHERE la) AS active_links, count(*) FILTER (WHERE la AND pa) AS good_links, min(sku) FILTER (WHERE la AND pa) AS sku FROM v GROUP BY sp, sv) SELECT sp AS shopify_product, min(sku) AS example_sku, count(*) AS variants, count(*) FILTER (WHERE active_links = 1 AND good_links = 1) AS ok, count(*) FILTER (WHERE NOT (active_links = 1 AND good_links = 1)) AS problem FROM per GROUP BY sp ORDER BY sp;"
