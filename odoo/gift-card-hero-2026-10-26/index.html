Gift cards – physical cards without code & custom amounts blocked (26.10.2026)

Status 26.10.2026, 17:45: customer case fixed, root cause found, waiting for Gift Card Hero (Syncube) support.

Shopify store iqdogsport.myshopify.com · app Gift Card Hero • All-in-one by Syncube (installed 05.01, usage-based pricing). All checks were read-only except creating one replacement gift card. Customer names, e-mails and full codes are intentionally not stored here; look them up on the order.

1. Customer case

  • Order #IQD-95299 (21.05.2026): physical gift card, custom amount 125 €, created by Gift Card Hero as draft order #D21, paid, shipped by GLS on 26.05. The order confirmation e-mail showed a red error and no code.
  • The buyer gave the card to a friend. On 26.10 the friend wrote that the code (12 letters, ending …JDEN) is rejected at checkout as invalid.

2. Investigation (read-only)

CheckResult
Shopify → Gift cards export (77 cards, 05.04 – 24.10)No card ending jden, nothing for #IQD-95299
Gift Card Hero export queue (63 rows)Not in it – this export is the eGift e-mail queue, so physical cards never appear there

Result: the code existed only on the printed card. Nothing in Shopify, so checkout correctly said "invalid".

3. Fix done for the customer

  1. Shopify → Products → Gift cards → Create gift card with the exact code from the card, 125,00 €, doesn't expire, internal note with the order number. Saved without "code already exists" → confirms it never existed.
  2. Card is Active, also visible in Gift Card Hero → Reload balance (Code ending jden, 125/125 €).
  3. Did not use "Send Gift Card" (would e-mail store admin/buyer). Reply e-mail to the recipient: code is now active for 125 €.

4. Root cause – physical cards

Gift Card Hero does nothing for physical card sales with the current settings (no code generated, no code assigned, no e-mail). A Shopify gift card exists only if a person creates it by hand.

  • Since 21.09.2026 a staff member creates each card manually a few minutes before fulfilment (matched by amount and time: #IQD-98141, 98176, 98190, 98280, 98403, 98412, 98852, 98910, 98990 – all have a card).
  • Before 21.09 no card was created for these physical-card orders:

5. Custom amounts blocked

Choosing Benutzerdefinierte (custom amount) and clicking KASSE does nothing – for eGift and physical. Fixed amounts work.

POST https://iq-dogsport.de/a/gifthero/api/card/custom  → 400

  • Last successful custom order: #IQD-98910, 19.10.2026 (220 €). Broken since about 20.10.
  • Not the cause: Shopify billing (app is usage-based, no plan to downgrade), app permissions (all granted, active).
  • Other console errors are unrelated: rez-bis.js addEventListener (pre-order app), "preloaded but not used" warnings.
  • #IQD-95299 also came through this draft-order route.

7. How to check (read-only)

  • Does a code exist? Shopify → Products → Gift cards → search last 4 characters. Or Gift Card Hero → Reload balance.
  • Custom amount error: product page in a private window → DevTools → Network → filter custom → choose custom amount → KASSE → click the red request → Response tab.
  • Physical cards since a date: export orders with product "IQ Geschenkgutschein (Karte)" and compare with the gift card export (amount, date, customer).
