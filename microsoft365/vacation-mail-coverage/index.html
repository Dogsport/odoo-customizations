Vacation Mail Coverage

Microsoft 365 / Exchange Online · Created 2026-11-04 · Owner: Hamza Mohsin · Waiting on decision

Every employee on vacation must have an out-of-office reply naming a backup, and their emails must be forwarded to or visible to that backup. This page documents the problem, the setup, the decisions made and what is still open.

Team guide

Published in Odoo Knowledge (Workspace, readable by all internal users): Vacation Out-of-Office & Mail Backup – Guide. It contains a checklist, Outlook steps and a German/English template text.

Share settings: General Access = Can Read, Show in Workspace = Everyone, Share to web = off.

Employee self-service steps (Outlook on the web)

  1. Auto-reply: Settings → Account → Automatic replies → turn on, set time period, paste template (inside and outside organization) → Save.
  2. Forwarding: Settings → Mail → Forwarding → Enable forwarding → backup address → tick Keep a copy of forwarded messages → Save.
  3. After vacation: turn forwarding off. The auto-reply ends by itself if an end date was set.

Admin procedure (central setup)

Use when an employee forgot, is already away, or if central setup is chosen. Path: admin.microsoft.com → Users → Active users → [employee] → Mail.

  1. Read and manage permissions → add backup with Read and manage (Full Access). The mailbox appears in the backup's Outlook within about an hour. This is the only way the backup also sees emails that arrived before setup.
  2. Manage email forwarding → forward to backup → tick Keep a copy of forwarded emails.
  3. Manage automatic replies → turn on with end date and backup name.
  4. Test: send a mail from another account, check the forward arrives and the auto-reply comes back.
  5. After the vacation: remove forwarding and Full Access again.

Before opening a mailbox: get Patricia's or Florian's written OK and inform the employee (German data protection, especially if private use of email is allowed).
