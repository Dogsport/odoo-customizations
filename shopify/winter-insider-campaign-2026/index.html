Winter Insider Campaign 2026 – MagDock voucher

How the free IQ Futtertasche MagDock for buyers of the new winter models works, what was set up in Shopify on 16.10.2026, and what to do until the vouchers expire.

← All documentation OverviewHow it worksSetupTimelineTasksCustomer serviceTestingFiles

Overview

Offer: customers who ordered an IQ Winterparka Unisex (329,00 €) or an IQ Zip-off-Wintermantel Damen (349,00 €) between the newsletter and Sunday 18.10.2026, 23:59 get a free IQ Futtertasche MagDock (value 35,90 €).

Redeem: once MagDock is in stock, with the code MAGDOCK-INSIDER, one MagDock per customer, until 31.03.2027. Shipping for the MagDock order may apply.

Tools: Shopify only (Flow, customer segment, discount, order confirmation email) + Brevo newsletter. No extra app.

How it works

1 · OrderCustomer buys Winterparka or Wintermantel
→
2 · FlowShopify Flow adds customer tag magdock-insider
→
3 · SegmentCustomer appears in segment "MagDock Insider"
→
4 · EmailOrder confirmation shows the voucher box with the code
→
5 · RedeemMagDock in cart + code → 0 € (only for tagged customers)

The code itself is the same for everyone. It is "personal" because Shopify only accepts it from customers in the segment (checked by the email address at checkout). If the code is shared, it is rejected for anyone else.

If the winter order is cancelled or the winter item is refunded, two more Flows remove the tag, so the voucher stops working.

Open tasks

After the campaign (from 19.10.2026): Shopify → Apps → Flow → "Tag magdock insider customers for winter coat orders" → Turn off. Keep the two remove-tag workflows on until 31.03.2027.
  • Check the segment "MagDock Insider": number of customers = number of qualifying orders (minus cancellations/refunds).
  • Align the MagDock availability date (product page "Ende Oktober" vs. newsletter "ab November").
  • When MagDock arrives: test the code once with a tagged test customer, then send the redeem email to the segment.
  • After 31.03.2027: optionally remove the tag from customers and archive the discount.

Testing

  1. Test order for a winter model with your own email → confirmation shows the voucher box.
  2. Flow → Recent runs: True → Add customer tags; customer has the tag; segment shows 1.
  3. Cancel the test order → remove-tag Flow runs → tag gone.
  4. When MagDock is in stock: tagged customer + code → 0 €; a different email → code rejected.
