Product merge: colour products → one product with variants

How we merge several Shopify products (one per colour) into one product with the options Farbe and Größe, without breaking the Odoo stock sync, the reviews or the old URLs.

Owner: Hamza Mohsin · First done: MFJ 3.0 Unisex (October 2026)

How it works in one picture

ODOO (stays as it is)                  SHOPIFY
3 products, e.g.                        1 new product "IQ Multifunktionsjacke 3.0 Damen"
  Women Black   MJD3.BK.XS…4XL  ──┐      Farbe × Größe = 24 variants
  Women Blue    MJD3.BL.XS…4XL  ──┼──►   linked per variant by SKU
  Women Olive   MJD3.OL.XS…4XL  ──┘      (Emipro connector)

Old Shopify products (Schwarz, Olive, Blau) → Draft, never deleted
  - keep their reviews (Judge.me product group)
  - their URLs redirect to the new product

Key rule: Odoo is the source of truth for stock. The connector matches Shopify variants to Odoo variants by SKU (Internal Reference). That's why the new product keeps exactly the same SKUs as the old ones, and nothing is merged in Odoo.

Never do this

  • Never delete the old products: their reviews disappear from the group.
  • Never change SKUs of merged variants.
  • In Odoo, never use "Update/Export product" or "Unpublish" on a merged product. Only Export stock.
  • Never leave old and new products Active at the same time (duplicate listings).

Step 1: Odoo check – every SKU exists once

Why: the Emipro connector links Shopify variants to Odoo variants by SKU. If a SKU exists twice in Odoo, the connector may pick the wrong (empty) product, and Shopify shows "Ausverkauft" (sold out).

Do

  1. Odoo → Sales (or Inventory) → Products → Product Variants (list view).
  2. Search Internal Reference with the SKU prefix, e.g. MJD3 or MFJ3.
  3. Turn on the Archived filter too.
  4. Count: the number of rows must equal the number of variants you will create (e.g. 3 colours × 8 sizes = 24). Each SKU exactly once.

If a SKU exists twice

  • Find the duplicate: usually 0 stock, no attribute values, created by the connector.
  • Check its smart buttons (Sold, In/Out). Never delete; it may have history.
  • Rename its Internal Reference to …-ALT and archive it.

Don't

  • Don't merge the Odoo products. 3 Odoo products behind 1 Shopify product is correct.
  • Don't create new fields in Odoo for this.

Step 2: Build and import the new Shopify product (Draft)

Why a new product instead of editing an old one: the old products stay untouched and live until the switch, so nothing breaks while we build.

1. Export the old products

Shopify → Products → tick the old colour products → Export → Selected products → CSV for Excel.

2. Build the import CSV

One product, all variants. From the export: - Handle: a temporary one, e.g. iq-multifunktionsjacke-3-0-damen-neu - Title: without colour, e.g. IQ Multifunktionsjacke 3.0 Damen - Option1 Name = Farbe, Option2 Name = Größe - Colour values exactly as in the theme swatch list: Schwarz, Graublau, Olive - Copy per variant: SKU, barcode, price, compare-at price, cost, weight (unchanged) - Variant Inventory Qty: empty (Odoo sends stock later) - Status: draft - Vendor IQ Dogsport, Type Bekleidung, tags from the old products - Images: all images of the old products; each colour's first image as its variant image - Remove product-level values that belong to one colour (e.g. Color metafield, review count)

Example: ../merges/mfj-3-0-damen/MFJ3-Damen-new-product-import.csv

3. Import

Products → Import → upload → don't tick "Overwrite products with matching handles" → preview must show 1 product with all variants → Import products.

4. Check and complete the product

  • Status Draft, all variants, price, images
  • Category (often empty after import): e.g. Sport Jackets
  • Vendor IQ Dogsport (not "IQ Dogsport GmbH")
  • Description: no fixed review numbers ("aus 102 Bewertungen" → "Alle Bewertungen lesen")
  • Publishing: tick all sales channels (Online Store etc.). Status stays Draft. Needed so Judge.me can see the product.
  • Variant Galerie metafield per variant: that colour's images, front view first

Step 3: Link the new product in Odoo and sync stock

How the connector works

The connector keeps a link row per Shopify variant, each pointing to one Odoo variant (matched by SKU). Before the old links are removed, one Odoo variant has two links:

Odoo variant MJD3.OL.M (stock)
  ├─ link → OLD Shopify product "Damen Olive", variant M
  └─ link → NEW Shopify product "Damen", variant Olive / M

Export stock sends each Odoo variant's free stock (on hand − reserved) to all its links. So old and new products show the same numbers during the changeover.

Do

  1. Copy the new product's ID from the Shopify admin URL (…/products/1234567890).
  2. Odoo → Shopify → Operations → Import products → Product IDs = that ID → Execute. If needed: Queues → Product Data Queue → Process.
  3. Odoo → Shopify → Products → search the Shopify Template Id → Variants tab:
  4. one line per variant (e.g. 24)
  5. each line → the right Odoo variant with the same SKU
  6. Operations → Export stock. Check Logs for errors.
  7. Shopify: the new product's total stock = the old products' total.

Notes

  • "Product Template" on the record shows only one Odoo product name. It's just a label.
  • Line titles may still show old product names. That's cosmetic, don't "fix" it with an export.
  • Shopify shows on hand − reserved, so small differences to Odoo "On Hand" are normal.

Step 4: Reviews – Judge.me product group

Judge.me can no longer move reviews between products (confirmed by Judge.me support, Shopify rules). Instead we use a static product group: every product in the group shows all reviews of the group, with verified badges. Included in our plan (Awesome).

Do

  1. Shopify → Apps → Judge.me → Settings → Product groups → Create static product group.
  2. Name, e.g. MFJ 3.0 Damen.
  3. Add products manually → remove the filter "In store: Yes" (otherwise Draft products are hidden) → search a short term, e.g. Multifunktionsjacke 3.0 Damen.
  4. Tick the new product and all old colour products → Add → Save.
  5. Wait 2–5 minutes, reload. Old products show the group total. The new product may show 0 in this list; check its product page in Preview instead.

If the new product isn't found

  • It must be published to a sales channel (Draft is fine) → save it once → wait.
  • Still missing: ask Judge.me support (Fin chat) to sync the product ID.

Rules

  • Never delete the old products. Their reviews are what the group shows.
  • Don't also import the review CSV, or reviews show twice.
  • Each review shows "Bewertung für [old product]". After go-live that link redirects to the new product.

Step 5: Go live – handles, status, redirects

Takes about 2 minutes. Do the steps directly after each other.

Before

  • New product: all checks from steps 2–4 done, Preview looks right.
  • Decide the final URL. We keep the old main product's URL (it has the Google ranking), e.g. iq-multifunktionsjacke-3-0-unisex.

Do

  1. Old main product (e.g. Schwarz) → Search engine listing → handle → add -alt (e.g. iq-multifunktionsjacke-3-0-unisex-alt) → untick "Create URL redirect" → Save.
  2. New product → handle = the freed URL (e.g. iq-multifunktionsjacke-3-0-unisex) → Save. "Create URL redirect" may stay ticked (temporary handle → final handle).
  3. New product → Status Active.
  4. Old products → Status Draft (all of them).
  5. Online Store → Navigation → URL Redirects → create, each pointing to the new URL:
  6. /products/<old-main>-alt
  7. /products/<old-olive-handle>
  8. /products/<old-blau-handle> Test the /en/ versions; add them only if they show 404.

Errors we saw

  • "Handle already in use": the old product still has it. Do step 1 first.
  • "Target can't redirect to another redirect": a redirect already exists from the target URL. Delete it in URL Redirects first (no chains A → B → C).

Rollback

New product → Draft; old products → Active; swap the handles back. Odoo keeps syncing both, as long as the old links in Odoo are not removed yet.

Step 6: After go-live

Same day

  • ☐ Open the old URLs (DE + EN) in a private window: they land on the new product.
  • ☐ Collections: manually sorted collections put new products last. Products → Collections → each collection → drag the new product to the old position.
  • ☐ Product page: colour switch, gallery, reviews count, stock per variant.
  • ☐ Odoo → Shopify → Logs: no new errors.

After a few days without problems (with Florian)

  • ☐ Odoo: in each old Shopify product record → Variants tab → 🗑 every line. This only removes the link. From now on stock goes only to the new product.
  • ☐ Shopware redirects: point directly to the new URL (no double redirect).
  • ☐ EN translations, Google Merchant feed check.

Keep

  • Old products stay as Draft forever (reviews, order history).
  • Odoo products stay as they are.

Troubleshooting

Symptom Cause Fix
Shopify shows "Ausverkauft" although Odoo has stock Shopify variant linked to a duplicate Odoo product with the same SKU (0 stock) Step 1: rename duplicate to -ALT + archive; delete wrong variant lines in the Odoo Shopify record; re-import the Shopify product by ID
Odoo log INVALID_INVENTORY_ITEM A link points to a Shopify variant that was deleted Delete that variant line (🗑) in the Odoo Shopify product record
Odoo queue "SKU missing" Variant created in Shopify before the SKU existed in Odoo Create the variant/SKU in Odoo first, then import again
New product stock lower than old products Not all variants linked yet / export ran too early Check Variants tab (one line per variant), run Export stock again
Small difference Shopify vs Odoo On Hand Shopify gets on hand − reserved (open orders) Normal
New product not found in Judge.me Not published to a sales channel, or filter "In store: Yes" Publish (Draft is fine), remove the filter, wait; else ask Judge.me support
New product shows 0 reviews in the group list The list counts own reviews only Check the product page in Preview
"Handle already in use" Old product still has the handle Rename old handle to -alt first
"Target can't redirect to another redirect" Redirect exists from the target URL Delete that redirect first
New product at the end of a collection Collection sorted manually Drag it up in each collection
